# ミナと星苔の方位盤

## 第一章・北をなくした森

既存の3D RPGとは入口・実装・素材・セーブデータを分けた、森研究所の完全オリジナル見下ろし型2D JRPGです。昔ながらの「町、森、研究所、会話、探索、ランダム戦闘、コマンド戦闘、成長」という遊び方だけを参考にし、人物、敵、地図、物語、名称、画面構成、画像素材は本作専用に制作しています。

森研究所の星苔方位盤から北の光が消え、道が同じ場所へ戻るようになりました。ミナは灯枝村を出発し、星苔林道に残る三つの標光を集め、森研究所の地下方位観測層へ向かいます。

### 第1章の構成

- 灯枝村：研究員や村人との会話、休憩、道具の購入、任意の収集依頼
- 星苔林道：三つの標光、宝箱、青いどんぐり、通常戦闘、回復と記録
- 森研究所・地下方位観測層：三つの台座、観測記録、ボス戦、第1章の結末
- 主人公：ミナ
- 通常敵4種、章ボス1種
- コマンド：たたかう、観察、研究術、道具、守る、逃げる
- 成長：経験値、レベル、HP・SP・攻撃・防御の上昇
- 所持品、装備、買い物、宝箱、イベント進行
- キーボードとiPad向けタッチ操作

独立セーブキーは `mori-lab-jrpg-ch1-v1` です。マップ、座標、向き、能力、経験値、所持金、装備、道具、宝箱、収集物、イベント、ボス、章完了状態を保存します。

## ピクセルアート素材

ゲーム内の人物、敵、地形、建物、草木、小物は、CSS図形ではなく実画像の透過PNGとして収録しています。Canvas 2Dではアンチエイリアスを無効にし、固定論理解像度から整数比に近い拡大を行います。

公開用のゲーム素材は `public/game-assets/rpg2d-ch1/` にあります。

- ミナ4方向：4点
- NPC：4点
- 通常敵と章ボス：5点
- 地形・壁・床・水・樹冠など：16点
- 建物・樹木・家具・宝箱・灯りなど：12点
- 合計：41点

制作元と加工済みシートは `design/rpg2d-chapter1/source/` に保存しています。

- `characters-source-v1.png` / `characters-alpha-v1.png`
- `enemies-source-v1.png` / `enemies-alpha-v1.png`
- `tiles-source-v1.png`
- `props-source-v1.png` / `props-alpha-v1.png`

`build_pixel_assets.py` は、上記シートを個別のゲーム用PNGへ切り出し、最近傍補間で規格化する再生成スクリプトです。透過画像は平坦なマゼンタ背景からソフトマットと色かぶり除去を行ったうえで使用しています。

## ImageGen制作記録

内蔵ImageGenモードで、次の五つのプロンプト群を本作専用に生成しました。

1. ミナ4方向と村人・研究員・商人のキャラクターシート
2. 森の通常敵4種と鹿型の章ボス
3. 草地、道、水、床、壁、屋根、樹冠などの地形タイル
4. 家、研究所、木、家具、宝箱、標識、記録灯などの建物・小物
5. 第1章の公開用ソーシャルプレビュー

各依頼では、精密な手描き風ピクセルアート、限定色、硬いピクセル輪郭、正面または見下ろしゲーム視点、既存作品の固有表現を使わないことを指定しました。既存ゲームの画像、音楽、マップ、人物、敵、固有名称は転用していません。

公開用プレビューは `public/og-rpg2d-v1.png` です。過去作品のプレビュー画像は削除せず、別版として保存しています。

## 実装基準

- Canvas 2D、論理解像度640×360
- `imageSmoothingEnabled = false`
- M1 iPadを最低動作基準とする軽量な2D描画
- 方向キー / WASD、決定 / 取消キー
- Pointer Events、pointer capture、cancel・lost capture時の入力解除
- タッチボタンは押し続け移動に対応
- 画面遷移、重要アイテム、戦闘終了、ボス後、手動操作で保存
- 既存3D RPGとは別コンポーネント、別CSS名前空間、別素材、別セーブ
