# 木漏れ日の観測林

2026-09-18。研究員の「ゲーム担当に任せる」「自由にやって」の依頼による独立した3D森の試作。回転・拡縮、木へのタップ、鳥の離陸・飛行・着枝を中心とする。既存ゲーム・セーブを変更しない。まずローカル確認、公開は別途確認する。

実装：8本の木、16羽の鳥、水辺、回転・拡縮、タップのドラッグ判別、朝夕の光、観測ボタン。葉と草はインスタンス描画、解像度比上限1.5、影1024。非表示時の進行停止、動き軽減設定対応。ストレージ読み書きなし。

検証：build成功、対象ESLint成功、既存32テスト成功。ブラウザで3D描画と観測ボタンによる鳥の離陸メッセージを確認。縦長画面の初期カメラを調整。M1 iPad実機のFPS・ピンチ操作は未検証。
