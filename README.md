# 森研究所ゲーム集

森研究所から生まれた、ブラウザ・Mac・iPhone・iPadで遊べる小さなゲーム集です。ゲームをクリアすると共通の木が育ち、将来は森研究所へ成長します。

## 収録ゲーム

1. ミナと気配の森（地図が広がる3レベル）
2. 研究員を座らせろ！（難易度が上がる5レベル）
3. ミナ世界クイズ（問題数が増える3レベル）
4. 森研究所を育てよう（目標つき育成モード）

「昼の星への道」と「ちょっとだけボタン」は、遊び方を再検討するため研究温室で休眠中です。

## 運用方針

- ミナシリーズに関する出題や紹介は、公開確認済みの範囲だけを使う。
- セーブデータは各端末のブラウザ内へ保存する。
- 旧版のセーブデータを引き継ぐ。
- クリア実績に応じて共通の木へ成長ポイントを加える。
- 森研究所サイトやミナシリーズサイトとは別のゲーム用プロジェクトとして管理する。
- ゲームの追加や大きな変更は、一つずつ検証してから公開する。

## 開発

Node.js 22以降とpnpmを使用します。

```bash
pnpm install
pnpm run dev
pnpm run build
```
