# 森研究所ゲーム集

森研究所から生まれた、ブラウザ・Mac・iPhoneで遊べる小さなゲーム集です。

## 収録ゲーム

1. ミナと気配の森
2. 昼の星への道
3. 森研究所を育てよう
4. ちょっとだけボタン
5. 研究員を座らせろ！
6. ミナ世界クイズ

## 運用方針

- ミナシリーズに関する出題や紹介は、公開確認済みの範囲だけを使う。
- セーブデータは各端末のブラウザ内へ保存する。
- 森研究所サイトやミナシリーズサイトとは別のゲーム用プロジェクトとして管理する。
- ゲームの追加や大きな変更は、一つずつ検証してから公開する。

## 開発

Node.js 22以降とpnpmを使用します。

```bash
pnpm install
pnpm run dev
pnpm run build
```
