# ミナと森研究所 第一章・消えた記録

## 完成範囲

- M1 iPadを最低基準にした、初代PlayStation時代ほどの規模のオリジナル3D RPG
- 村、森、森研究所を歩ける一章完結のフィールド
- NPC会話、記録片の収集、通常戦闘、経験値、レベルアップ、ボス戦
- 自動保存と手動保存、同じ端末での続きから再開
- キーボードとiPadのタッチ操作

## 第一章の流れ

1. 石灯り村で研究員から、森研究所から消えた三つの記録について聞く。
2. 森を探索し、記録片を集めながら迷い影と戦う。
3. 記録片をそろえて森研究所へ進む。
4. 記録を食べる影を倒し、研究所の記録灯を取り戻す。

## 制作方針

- 人物、建物、木、岩、敵、収集物はThree.jsの低ポリ形状で生成する。
- 外部3Dモデルや外部テクスチャに依存せず、初回読込と容量を抑える。
- 描画解像度は端末比率の最大2倍、影は1024、ポストプロセスは使わない。
- 毎フレームの値はゲーム内部で持ち、画面表示の更新頻度を抑える。
- WebGLが利用できない場合は、ゲーム集へ戻れる案内を表示する。
