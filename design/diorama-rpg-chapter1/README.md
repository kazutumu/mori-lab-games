# ミナと風綴りの丘　第一章・眠る風車

森研究所ゲーム集の12作目として制作する、完全オリジナルの3DジオラマJRPGです。昔ながらのJRPGが持つ「仲間と歩く・敵に接触してコマンド戦闘へ入る・町と野外を往復して章を解く」という遊び方だけを参照し、既存作品の人物、固有名詞、敵、地図、画面構成、画像、音楽は使用しません。

## 作品の軸

- 主人公：ミナ（観察、回復、弱体化）
- 仲間：風車整備士トワ（前衛、防御）／風音採集員スイ（遠距離、補助）
- 舞台：風綴り村、風鈴丘と綴り森、森研究所・風向分室、眠る風車・地下機関層、織り店、風待ち宿
- 物語：「直す前に、なぜ止まったのかを聞く」。止まった風車は壊れたのではなく、幼い風種を強風から守っていた
- ボス：毛糸と木片でできた丘守「眠り角ムルム」。戦闘後は消滅させず、三人の観察と調整で共存する

進行は、村でトワ加入、三つの風綴り、スイ加入、やわらか歯車の発見、三人それぞれの準備、ムルム戦、村への報告の順です。丘には避けて通れる敵が見えており、接触した場所のジオラマをそのまま舞台にしてコマンド戦闘へ移ります。仲間の加入人数とスイの調律は攻撃・連携術へ反映されます。

## 操作と保存

タッチの方向パッド・決定・コマンド・取消・保存と、矢印／WASD・Z／Enter／Space・X／Escape・Mに対応します。独立セーブキーは `mori-lab-diorama-rpg-ch1-v1` です。マップ、座標、仲間、進行、レベル、経験値、HP／SP、所持品、装備、宝箱、撃破済み敵、ボス、章クリアを保存します。

## M1 iPad基準

- Three.jsの固定斜め追従パースカメラ
- DPR上限2、影1024px、ポストプロセスなし
- 草木や小物は同形状・同素材を再利用
- HUD更新を描画フレームから間引き、草木はInstancedMesh、風車はLODを使用
- 非表示時は描画を止め、復帰時に入力を解除
- `pointerup`、`pointercancel`、`lostpointercapture`、`blur` に対応
- ResizeObserver、WebGL context loss案内、geometry／material／texture／rendererの終了処理

## ImageGen素材

生成は組み込みImageGenを使用し、出力元を `source/` に残したうえで、実行用の軽量素材を `public/game-assets/diorama-rpg-ch1/` に派生保存しています。

### プロンプトセット

1. **マテリアル・アトラス** — 2×2の真上視点。苔の草地、暖色の土道、蜂蜜色の石積み、青緑の銅屋根。手作りジオラマ素材として継ぎ目なく使える構成。人物、文字、UI、既存作品の意匠なし。
2. **三人の人物画** — 書影をミナの容姿・服装だけの参照に使用。トワ、ミナ、スイを三分割し、塗装した粘土・布・木でできた精密なミニチュア人物として正面寄りに描く。文字、UI、既存作品の意匠なし。
3. **SNSカード** — 16:9の丘村ジオラマ、眠る風車、三人の観測隊、風車角を持つ羊型の丘守。深緑の布地パネルに作品名と「M1 iPad・3D DIORAMA RPG」を配置。
