# 森研究所ゲーム集

森研究所から生まれた、ブラウザ・Mac・iPhone・iPadで遊べる小さなゲーム集です。ゲームをクリアすると共通の木が育ち、将来は森研究所へ成長します。

## 収録ゲーム

1. ミナと気配の森（地図が広がる3レベル）
2. 研究員を座らせろ！（難易度が上がる5レベル）
3. ミナ世界クイズ（問題数が増える3レベル）
4. 森研究所を育てよう（目標つき育成モード）
5. ミナと消えた時間（立体風の時計仕掛けの村を歩く試作）
6. ミナと風待ち島（島一つと五つの風門をめぐる軽量セーリング試作）
7. ミナと風待ち島 3D（立体のミナが乗る船で島をめぐるWebGL実験版）
8. ミナと風待ち島 M1・朝の手紙（三つの風を集めて島の桟橋へ手紙を届ける航海ゲーム）
9. ミナと夜の研究路（表紙基準の人物イラストで右へ進む完全横スクロール2Dアクション）
10. ミナと森研究所 第一章・消えた記録（村・森・研究所を歩くM1 iPad基準の小規模3D RPG）
11. ミナと星苔の方位盤 第一章・北をなくした森（海に浮かぶ一島を斜め見下ろしで旅するピクセルジオラマJRPG）
12. ミナと風綴りの丘 第一章・眠る風車（風綴り村・風鈴丘・森研究所の分室を巡る3DジオラマRPG）

「昼の星への道」と「ちょっとだけボタン」は、遊び方を再検討するため研究温室で休眠中です。

## 運用方針

- ミナシリーズに関する出題や紹介は、公開確認済みの範囲だけを使う。
- セーブデータは各端末のブラウザ内へ保存する。
- 旧版のセーブデータを引き継ぐ。
- クリア実績に応じて共通の木へ成長ポイントを加える。
- 森研究所サイトやミナシリーズサイトとは別のゲーム用プロジェクトとして管理する。
- ゲームの追加や大きな変更は、一つずつ検証してから公開する。
- 「ミナと消えた時間」は端末で軽く動かすため、画像や3Dエンジンを使わずコードだけで立体風に描画する。
- 「ミナと風待ち島」も同じ方針で、海・船・島をコードだけで軽量に描画する。
- 3D版は別入口で必要なときだけ読み込み、軽量版と既存ゲームの起動速度を守る。
- M1版も完全な別入口とし、GPU波面・高解像度影・空・光の仕上げを対応端末だけで読み込む。
- 「ミナと夜の研究路」は、文庫版第1巻の表紙を基準にしたミナと四人の番人を、背景透過の2Dスプライトとして読み込む。
- 「ミナと森研究所 第一章・消えた記録」は、低ポリ3D素材をコードで生成し、会話・収集・戦闘・経験値・レベル・ボス・端末内セーブを一章にまとめる。
- 3D RPGの進行データは `mori-lab-rpg-ch1-v1` として端末内に保存し、ゲーム集共通のクリア実績とは分離する。
- 「ミナと星苔の方位盤 第一章・北をなくした森」は、人物・敵・地形・建物・草木・小物を本作専用のPNGピクセルアートで描く、斜め見下ろしの一島ジオラマとする。
- 2D JRPGは1024×576のCanvas 2Dへ64×32の菱形地面を等角投影し、海に浮かぶ島の側面と高低差、72×96の直立ピクセル人物、建物・草木・小物を描画する。探索・会話・収集・買い物・装備・コマンド戦闘・経験値・レベル・ボスを第一章にまとめる。
- 等角フィールドの操作は8方向に対応し、上下左右は途中の1マスごとに衝突・出入口・戦闘判定を行う。斜め4方向は入口や人物の前で使える1マス移動とする。
- 2D JRPGの進行データは描画方式の変更後も `mori-lab-jrpg-ch1-v1` として端末内に保存し、既存セーブとの互換性を維持する。3D RPGとゲーム集共通のクリア実績からは分離する。
- 「ミナと風綴りの丘 第一章・眠る風車」は、舞台・人物・物語・敵・地図・ゲーム内容を本作のために作った森研究所の完全オリジナル作品とする。
- 3DジオラマRPGはM1 iPadを最低基準とし、低ポリ形状、固定斜め視点、LOD、描画倍率と影の上限によって、箱庭の密度と安定した操作を両立する。
- 地表・石・屋根・道の質感と人物ポートレートは、本作専用素材として `public/game-assets/diorama-rpg-ch1` に保存する。
- 3DジオラマRPGの進行データは `mori-lab-diorama-rpg-ch1-v1` として端末内に保存し、既存3D RPG、2D JRPG、ゲーム集共通のクリア実績から分離する。

## 開発

Node.js 22以降とpnpmを使用します。

```bash
pnpm install
pnpm run dev
pnpm run build
```
